# Reign Launch Page

Build a premium e-commerce product landing page for a new SARKAR fragrance called REIGN.

1. PRIMARY OBJECTIVE

Recreate the exact visual structure, spacing, proportions, typography hierarchy, navigation style, product layout, buttons, variant selector, and minimalist aesthetic of the provided reference screenshot.

The provided screenshot is the PRIMARY DESIGN REFERENCE.

Do NOT redesign the page into a generic modern e-commerce website.

Do NOT add unnecessary sections, gradients, cards, rounded UI, glassmorphism, excessive animations, or a completely different layout.

The final website should feel like the same SARKAR website shown in the reference, but with the new product REIGN replacing ORION as the featured product.

Maintain the same premium, minimal, monochromatic SARKAR design language.
